# 第一讲 语法的基本知识

## 笔记 程序语言缺乏「说」的性质

与自然语言相比，程序语言看似有一种「只读写而不说」的性质。
程序语言目的在于精确地描述如何「做」。

但是在 AI 辅助写代码的时代，这种单一的职责显然不够用了，
因为 AI 会生成大量代码，而这些代码，在自然的编程过程中，
只是一种更丰富的，符合人类认知过程的结果。

我们需要一种方式来用自然语言记录编程过程的中间结果，
来帮助人类快速理解大量代码。

最简单的方案就是把编程的思考过程记录在 markdown 文档中，
把代码作为 markdown 中的「代码块」，
语言的编译器和解释器可以直接处理 markdown 文档。
markdown 可翻译为「轻记」为「轻量级标记语言」的缩写。

## 笔记 语法与语义之分在逻辑系统中的类比

语法是比语义更简单的一个范畴。

对于类型系统而言：

- 「语法」类似于可以类型检查出的简单错误；
- 「语义」类似于程序运行时的行为错误。

对于辅助证明系统而言：

- 「语法」类似于可以自动判断的基础等价关系，即定义等价或可计算等价；
- 「语义」类似于需要被证明的复杂等价关系，即命题等价。

从分析角度看，我们先分析语法再分析语义，好像语法是语义的基础。
但是在「分布主义」的观点中，正是在表达语义的过程中，慢慢形成了语法。
