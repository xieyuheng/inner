# 复习层次分析

## 语法与语法单位

语言是声音和意义相结合的符号系统。

语法是语言中，
由小的音义结合体组合成大的音义结合体，
所依据的一套规则。

根据音译结合体大小的不同，
可以定出以下单位：

| 单位 | 说明                             |
|------|----------------------------------|
| 语素 | 最小的单位                       |
| 词   | 最小的可独立运用的语法单位       |
| 词组 | 由词根据句法规则组成             |
| 句子 | 一定有句调，是最大一级的语法单位 |

英语：

- 语素 -> 词 -> 词组 -> 句子 -- 组合关系

汉语：

- 语素 -> 词 -> 词组 -- 组合关系
- 句子 = 句调 + 词 或 词组 -- 实现关系（或者说解释关系）

所谓句调，最典型的是句子中音阶逐渐升高，被解释为疑问句。
而句子中音阶逐渐下降，被解释为陈述句。

所谓解释，就是人对符号的理解。

## 语音对语法的影响

### 音节对语法的影响

比如音节对词的影响。

单音节的花名，荷花和桂花要加「花」，才能成花名；
而双音节的花名，牡丹和玫瑰，可以省略「花」不说。

树名也是如此，比如单音节的说：柏树、杨树、柳树、槐树；
双音节的说：梧桐、银杏、木棉、白桦。

这是因为现代口语中，汉语有强烈的双音节韵律。

比如形式动词：「加以」「进行」。
这些动词后面带的动词都必须是双音节的。

比如动词修饰名词，一般要加「的」，
比如「买的衣服」「写的文章」，
如果不加「的」就是动宾结构了。
但是一部分双音节动词，可以直接修饰名词，
比如：「研究课题」「学习目的」。

### 重音对语法的影响

比如「都」字的重音不同，
所表达的意义不同（我们用 ^ 前缀标记重音）：

- 「他们^都回来了」表达总扩。
- 「他们都^回来了」表达已经。
- 「三岁^小孩都知道」表达尚且、甚至。

比如动词（双音节）+ 名词：

- 动宾结构：学习^英语、参观^校园
- 定中结构：^学习材料、^研究课题

定中结构，就是定语形容中心语，也是偏正结构。

有的词组，根据自然重音不同可以表达两种结构：

- 出租^汽车、进口^钢材
- ^出租汽车、^进口钢材

至于为什么有如此的重音赋值规律，
可以理解为，重音自然地出现在听者所关心的词上，
比如在定中结构中，中心词常常表示宽泛的类型，
反而是定语才带有重要的信息。

述补结构或者说动补结构，
有一种类型是带「得」的。

比如「洗得干净」：

- 洗得^干净：状态补语
- ^洗得干净：可能补语

### deepseek 解释重音规律

- 韵律语法中的“核心重音”规则（名词化的代价）

  根据汉语韵律句法学理论（如冯胜利），
  动词短语（VP）和名词短语（NP）的内部重音赋值规则不同：

  - 在动词短语（动宾）中，动词是核心，
    但宾语是信息量最大的“新信息”，
    因此自然焦点落在句末宾语上（核心重音在宾语）。
  - 在定中短语（偏正）中，当动词短语被“降级”为定语时，
    它失去了作为谓语核心的资格，变成了修饰成分。
    此时，中心语（名词）往往是泛指的“类名”（如“材料”），
    而真正起到“限定指别”作用的是定语（告诉你是“学习用的”还是“教学用的”）。
    为了突出这个区分功能，重音必须“左移”到定语上。

- 信息焦点理论（旧信息 vs 新信息）

  从信息传递的角度看：
  - 动宾（学习^英语）：
    动词“学习”是已知动作，
    宾语“英语”是听话人最关心的具体对象（新信息），
    所以重读宾语。
  - 定中（^学习材料）：
    中心语“材料”在语境中往往是一个已知范畴（比如我们在聊教材），
    而定语“学习”是告诉听话人“是哪种材料”，起到分类和限定作用。
    分类信息（定语）比类名（中心语）更具信息增量，所以重读定语。

- 音步节奏的“松紧”区别

   双音节定语（学习、研究）修饰双音节名词（材料、课题）时，
   为了体现结构的凝固性（定中结构比动宾结构在意义上更紧密，常常词汇化），
   左重音步会让整个词组听起来更像一个“复合词”，而非临时的句法组合。
   比如“^研究课题”听起来像是一个已经确定的项目名称，
   而“研究^课题”则更像一个动态的行为动作。

- 总结一句话：

  重音在定语上，是为了“降级”动词的动作属性，把它变成“属性标签”，
  从而把中心语从一个“临时受事”变成一个“固定类别名词”。
  这不仅是语音习惯，更是汉语为了区分“动宾”与“定中”而设计的精密语法策略。

在设计 meta-lisp 的中文语法时，
「列表长度」「列表排序」等等大多都是定中结构，
或者说偏正结构，因此重音在「列表」。

### 停顿对语法的影响

「咬死了猎人的狗」有两种解释：

- 「咬死了 猎人的狗」述宾结构
- 「咬死了猎人的 狗」定中结构

## 语义对语法的影响

按照前面的定义，
语法是人们对音义译结合体的组合方式的总结，
因此显然语义也会影响语法。

语法的问题，说到底，都是语义的问题。

比如程度副词「还」：

- 表示程度深，所修饰的形容词可以是褒义或贬义。
  比如：「我比你还高」。
- 表示程度浅，所修饰的形容词只是褒义，不能是贬义。
  比如：「这个房间还干净」。
  但是不能说「这个房间还脏」。

此处的褒义与贬义，就是典型的语义影响语法。

## 自由与黏着

一个语法单位如果可以单独成句，
这个语法单位就是自由的。

比如：

- 「大」是自由的，因为可以单独成句。
- 「也」不是自由的，任何情况下都不能单独成句。

注意，自由黏着不是看实词虚词而分的。

但是并不是所有的实词都是自由的，
比如：妄图、加以、属于，都是黏着的动词。

名词也有粘着的，
比如：「这个馒头有什么吃头」中的「吃头」。

虚词大部分是黏着的，
然是也有自由的。

- 介词：修饰名词
- 连词：表示逻辑关系
- 副词：修饰动词和形容词
- 助词：实词后缀，通常轻声
- 语气词：放在句末，表示语气

其中副词有可能是自由的，
比如：「不」「也许」。

介词词组「把书」也是粘着的。

词组「扫地的扫地」不能单独成句，
至少要两个「扫地的扫地，擦桌子的擦桌子」才成句子。

句子没有自由黏着之分，
因为单独成句是自由的定义。

## 定位与不定位

语法元素的定位，指和别的语言成分组合时，所处的位置是固定的。

- 语素：「桌子」「椅子」中的「子」都必须在后面。
- 词：「刚」「刚刚」作为副词都必须在前面。
- 词组：「把书」等等「把」作为介词组合而成的词组，必须在前面。

句子没有定位一说，因为已经可以独立成句来表义了。

定位又有前置和后置之分。

## 简单与复杂

语法研究中的简单指单个词，
复杂指词组或句法结构。

比如「白」和「白白」作为副词：

- 「白白」只能修饰复杂：「白白干了一天」
- 「白」可以修饰复杂或简单：「白干了一天」「白干」

## 语法结构关系和语义结构关系

例如「张三吃了一个苹果」。

根据语法结构关系可分析为：

- 主：张三
- 谓：吃了一个苹果
  - 述：吃了
  - 宾：一个苹果
    - 定：一个
    - 中：苹果

实词之间的语义结构关系：

- 施事-动作：张三-吃
- 动作-受事：吃-苹果
- 数量-事物：一个-苹果

凡是有实词和实词互相组合形成的句法结构，
总是同时并存两种结构关系。

而这两种结构关系是两种不同的分析维度，注意不能混淆。

句法结构关系中的关系「主谓」等等，都是有序的。
但是语义结构关系是无序的。

# 语法构造的层次性和层次分析

## 线性的排列

从表面来看，句子和句法格式都是线性的排列。
但是内部元素的关系要看「层次的透景」。

- 人类在开始做程序语言的语法设计的时候，
  必然也是在模仿自然与语言的语法，
  设计为线性的排列，然后再做语法解析。

  而 LISP 的大胆创新在于，
  既然编写代码的媒介是文本编辑器，
  而不是线性的言说，
  那么就可以把经过语法解析的语法树，
  直接通过带有括号的符号表达式明显地写出来作为语法。

## 层次的透景

所谓「层次的透景」。

比如「他刚来」其结构可以分析为 `[他 [刚 来]]`。
比如「形声字」其结构可以分析为 `[[形 声] 字]`。

老师说，语言结构如此，
天下所有可以称之为结构的东西，
都是如此。

结构的三个特点：

- 整体性
- 可分割性
- 有规则性

和 SICP 所讲的程序语言的三部分很类似：

- primitive
- combination
- abstraction

比如对音节加以分析，
也可以获得声母、韵母、声调等组成元素：

- `[[声母 韵母] 声调]`

韵母 还可以继续分析：

- `[[声母 [韵头 韵部]] 声调]`
- `[[声母 [韵头 [韵腹 韵尾]]] 声调]`

比如「天」的音节 "tian1" 可以分解为 `[[t [i [a n]]] 1]`。

我们观察语言的构造，都能发现这种层次性。

## 层次分析

所谓「层次分析」，
就是在分析一个句子，或句法结构的时候，
将语法构造的层析性考虑进来，
并按其构造层次，逐层进行分析。
在分析时，指出每一层面的直接组成成分，
并说明直接组成成分之间的关系。
这种分析手段就叫「层次分析」。

比如「他刚来」其结构可以分析为 `[他 [刚 来]]`。
同时还要分析其元素之间的关系：

- `(主谓 他 [刚 来])`
- `(状中 刚 来)`

语法树用 `[]` 表示，关系用 `()` 表示。

当然，受限于文本编辑器，才用符号表达式来描述关系。
在黑板上，老师给出了更易读的图示。

## 层次分析包含 切分 与 定性 两部分内容

所谓「切分」就类似古文的句读。
所谓「定性」就是切分获得直接组成部分之后，
分析组成部分之间的关系。

## 层次分析举例

「他所写的文章」和「他所参观的工厂」，
显然应该有同样的语法结构。

但是如果做如下分析：

```meta-lisp
(语法分析 他所写的文章
  (定中 他 所写的文章)
  (定中 所写的 文章)
  (的字 所写 的)
  (所字 所 写))
```

第一个定中，就应该表示领属关系，
因为现代汉语中，人称代词做定语，都表示领属关系。

但是同样的分析方法对「他所参观的工厂」就不行了，
因为此时没有领属关系。

正确的分析方法是：

```meta-lisp
(语法分析 他所参观的工厂
  (定中 他所参观的 工厂)
  (的字 他所参观 的)
  (主谓 他 所参观)
  (所字 所 参观))
```

```meta-lisp
(语法分析 他所写的文章
  (定中 他所写的 文章)
  (的字 他所写 的)
  (主谓 他 所写)
  (所字 所 写))
```

「所参观」与「所写」的所字结构，
给动词增加了一些「指代」的意思，
但是仍然可以作为谓词来形成主谓陈述句。

「所」字本意处所。
「所＋动词」最早可能指代动作发生的处所，例如「所居」「所适」。
然后扩展到指代受事对象，例如「所见」「所闻」。

「他所写」描述的是「他」这个主语，
是这个所字结构所包含的动作的施事，
而不是说主语「他」与所指代的受事对象有领属关系。

虽然我们研究共时的语法结构，
但是所字结构所带有的指代性，
是我们理解这类句子时不可避免会想到的意义，
是没法被忽略的。

实际上，在做语法结构分析的时候，领属关系并不重要。

比如与英语相对比，在英语句子中都需要主语和谓语，
这是因为英语语法必须补足语义关系「施事 动作」中的「施事」。

而在中文句子中，如果我们认同「话题 说明」语法关系的话，
那么这种「话题 说明」结构，作为语法关系就是与语义关系解耦的，
可以对立于语义而存在的，可以独立于语义来分析的。
如果不解耦的话，没法解释很多省略主语的现象。

主语其实是语义关系中的「施事」，
如果「施事 动作」这种语义关系可以解耦，
那么例句中的领属关系，就也应该可以解耦。

语义关系可以像上面的例子一样，用来纠正语法关系，
但是不能主导语法关系。

同一个语法形式，不能应为语义关系不同，
而在不同的例句中，给出不同的语法分析。

因为语法形式一旦形成，例句之间的相似性本身，就定义着语法关系。

「我们所反对的」可以独立成句。
这种现象可以理解为「所」用来把主谓结构体词化，
主谓结构「我们反对」体词化为「我们所反对」，
不过在现代汉语中，和这个形式是粘着的，
必须在后面加上「的」才能成为自由的。

「他所写」分析为「所」嵌在主谓结构「他写」中间，
构成的名词性结构。

比如古汉语用「所」来把动词转化为名词：

- 「所见所闻」
- 「所问非所答」

嵌入型扩展的例子：

- 「洗干净」->「洗得干净」
- 「洗干净」->「洗不干净」
- 「跳过去」->「跳得过去」
- 「跳过去」->「跳不过去」
- 「飞机已经降落了」->「飞机听说已经降落了」
