# 层次分析

## 语法与语法单位

语言是声音和意义相结合的符号系统。

语法是语言中，
由小的音意结合体组合成大的音意结合体，
所依据的一套规则。

根据音译结合体大小的不同，
可以定出以下单位：

| 单位 | 说明                             |
|------|----------------------------------|
| 语素 | 最小的单位                       |
| 词   | 最小的可独立运用的语法单位       |
| 词组 | 由词根据句法规则组成             |
| 句子 | 一定有句调，是最大一级的语法单位 |

英语：

- 语素 -> 词 -> 词组 -> 句子 -- 组合关系

汉语：

- 语素 -> 词 -> 词组 -- 组合关系
- 句子 = 句调 + 词 或 词组 -- 实现关系（或者说解释关系）

所谓句调，最典型的是句子中音阶逐渐升高，被解释为疑问句。
而句子中音阶逐渐下降，被解释为陈述句。

所谓解释，就是人对符号的理解。

## 语音对语法的影响

音节会对语法产生影响。

比如音节对词的影响。

单音节的花名，荷花和桂花要加「花」，才能成花名；
而双音节的花名，牡丹和玫瑰，可以省略「花」不说。

树名也是如此，比如单音节的说：柏树、杨树、柳树、槐树；
双音节的说：梧桐、银杏、木棉、白桦。

这是因为现代口语中，汉语有强烈的双音节韵律。
